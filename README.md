# Yakıt Tüketiminin Dönüştürülmesi

### Projenin Amacı Nedir?
Python'da fonksiyonlar kullanarak yakıt tüketim değerlerini L/100 km ve MPG birimleri arasında dönüştürmek.

### Program Ne İşe Yarar?
Otomobillerin yakıt tüketim değerlerini litre/100 kilometreden galon başına mile (MPG) ve MPG'den litre/100 kilometreye dönüştürür.

### Program Nasıl Çalışır?
1. `liters_100km_to_miles_gallon()` fonksiyonu L/100 km değerini MPG'ye dönüştürür.
2. `miles_gallon_to_liters_100km()` fonksiyonu MPG değerini L/100 km'ye dönüştürür.
3. Hesaplamalarda mil, kilometre, galon ve litre dönüşüm katsayıları kullanılır.
4. Hesaplanan sonuçlar ekrana yazdırılır.

### Kullanılan Python Yapıları Nelerdir?
- `def`
- `return`
- `print()`
- Fonksiyon parametreleri
- Değişkenler
- Çarpma (`*`) ve bölme (`/`) operatörleri
